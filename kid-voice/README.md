# 小朋友模式样张（实验）

这是 anatomy 的一份**实验性**样张，用来验证「小朋友模式」：把一个概念讲给小学一年级（大约六七岁）听。

它**不改变** `SKILL.md` 的默认工作流，也不是正式输出形态。正式 skill 仍是面向成人的精细等距机器插图；这里只多了一个可以点、可以看字幕的儿童讲故事页。

本轮主题：**人为什么每天要喝足够多的水**。画面把人体想成一座每天都在忙的「小小身体工厂」，水是里面的快递员兼清洁工。

## 本次验证什么

- 画面是不是一眼仍像 anatomy 家的作品（等距、四调、画框、lit 选中）。
- 讲稿是不是够短、够口语，点零件能对上字幕。
- 「听故事」能不能按顺序点亮主角、切换大字幕（推进靠定时或再点，不靠音频）。

**本次未接真实 TTS 配音，先验证画面与讲稿。** 字幕和大字幕条就是这轮的声音替身。

## 怎么本地打开

在仓库根目录：

```sh
node kid-voice/water/check-narration.mjs
node kid-voice/water/build.mjs
```

然后用浏览器打开：

```
kid-voice/water/index.html
```

浅色主题：

```sh
node kid-voice/water/build.mjs --light
```

会另外写出 `kid-voice/water/index-light.html`。没有本地服务器也可以直接用文件打开（单文件、可离线）。

构建会先跑讲稿校验：句子太长或踩到禁用词（例如 `px`、`%`、新陈代谢、血液循环、调节体温）就会报错退出。

## MIMO_API_KEY

变量名只有 `MIMO_API_KEY`。它**只在构建期**读取，不会写进网页，也不会提交进仓库。

- 没有这个变量时：构建**不失败**。没有配音文件，页面仍可点、可看字幕。终端会印一行降级说明。
- 有这个变量时：本样张仍然**不会**调用外部 TTS。真实配音还没接上，避免在实验页里联网合成。

不要把密钥值写进任何文件。不要提交伪造的音频。

若以后要接 `mimo-v2.5-tts`，预览文件会写到 `kid-voice/water/voice/`（构建产物，不要手造）。

## 主角零件

| `part` | 画面上的东西 | 要念的那句 |
|---|---|---|
| `mouth` | 头顶的小嘴巴（喝水进门的料斗） | 小嘴巴是喝水的门。 |
| `factory` | 小肚子里的身体工厂 | 身体里的小机器要喝水。 |
| `courier` | 轨道上的水滴快递员 | 水滴去给小机器送水。 |
| `flush` | 前面冲走脏东西的水流槽 | 水把脏东西冲走。 |
| `exit` | 出汗的烟囱和上厕所的水滴出口 | 出汗的时候水会跑出去。 |

其余零件都是布景（底板、脚、尺、杯子、螺丝、标牌）。

点亮一个主角时，它发亮，其余变淡；下方大字幕换成那一句。按「听故事」会按表里的顺序走一遍，最后落到「水用掉了要再喝回来」。
